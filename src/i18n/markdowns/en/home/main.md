Due to the fact that currently there is no service in Poland providing chess games — since the only existing one has been suspended — and as this is an idea worth continuing, but neither PZSzach nor any WZSzach is interested in such a project, this website was created.

The website is intended to help players with their preparation, which will contribute to improving their sporting level. People who attempt to gain an unfair advantage by having their games removed from the database should familiarize themselves with concepts such as [honour](https://en.wikipedia.org/wiki/Honour), [human dignity](https://en.wikipedia.org/wiki/Dignity), and [fair play](https://en.wikipedia.org/wiki/Sportsmanship).

---

The game database can be used in accordance with the [license](/license) posted on the website. 🍺
